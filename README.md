## 🚀 使う順

1. **まず試す**：`土台版` フォルダを開き、スマホならQRを読み取る／パソコンなら html ファイルを開く
2. **読んで学ぶ**：`特典` フォルダの「特典1」から「特典4」を、番号の順に読む（本文の「特典○」と同じ番号です）

4. **自分で作る**：`ジェネレーターツール作成Skills.zip` を使う
5. **更新する**：`改修_Skills` の「01」の案内から読む

## 📱 ツールの開き方

### A. スマホで開く
1. `土台版` フォルダの **QRの画像（PNG）** をパソコンの画面に表示します。
2. スマホのカメラでQRを読み取ります。画面を明るくして、QRを大きく表示すると読み取りやすくなります。

### B. パソコンで開く：右クリック（一番おすすめ）
1. `土台版` フォルダを開き、**html ファイル**の上でマウスを右クリックします。
2. **「プログラムから開く」**（Macは「このアプリケーションで開く」）にマウスを合わせます。
3. 出てきた一覧から **「Google Chrome」** を選びます。
4. ツールが画面に表示されます。

### C. パソコンで開く：ドラッグ＆ドロップ
1. **Google Chrome** を起動しておきます。
2. html ファイルを、マウスの左ボタンを押したまま Chrome の画面まで引っ張り、ボタンを離します。

> 💡 **ファイルをダブルクリックして、メモ帳などの文字入力ソフトが開いた場合：** 英語の羅列（コード）が表示されます。故障ではありません。上の B か C の手順で、Chrome から開き直してください。
