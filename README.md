## 🚀 使い方（ツールの開き方）

パソコンでの開き方がわからない方も、以下の手順で行えば安全・確実に起動できます。インターネットに繋がっていなくても動く仕組みです。

### 1. 右クリックで開く（一番おすすめ）
1. `01_tool/` フォルダを開き、**`mail-generator-base.html`** の上で**マウスを右クリック**します。
2. 出てきたメニューの中から **「プログラムから開く」**（Macの場合は「このアプリケーションで開く」）にマウスを合わせます。
3. さらに横に出てくるアプリ一覧の中から **「Google Chrome」** を選択してクリックします。
4. 自動的にツールが画面に起動します。

### 2. 画面に引っ張って開く（ドラッグ＆ドロップ）
1. 普段通りに **Google Chrome** を起動しておきます。
2. `01_tool/` フォルダの中にある **`mail-generator-base.html`** をマウスで左クリックしたまま指を離さず、起動している Google Chrome の画面（白い背景の真ん中あたり）まで引きずっていき、マウスの指をパッと離します。

💡 **注意：** ファイルを普通にダブルクリックすると、メモ帳などの文字入力ソフトが開いて英語の羅列（コード）が表示されてしまうことがあります。その場合は、上記の手順で「Google Chrome」を選択して開き直してください。
