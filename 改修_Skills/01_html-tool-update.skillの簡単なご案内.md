## ① 技術的な仕組みと動作の流れ
本リポジトリの[html-tool-update.skill]は、Claude Codeに読み込ませて、HTMLファイルの修正・検証を自律的に実行させるための「Skills（スキル）」です。

LLM（生成AI）へのプロンプト指示だけではなく、ローカル環境で実際に動作する3つのPythonスクリプトと規約ドキュメントがパッケージになっており、AIが順番に実行して安全な自動アップデートを行います。

---

## ② パッケージの簡単なご説明

AIエージェントに「このスキルを使ってHTMLを修正して」と指示を出すと、AIは `SKILL.md` の手順に従い、以下の4つのファイルを裏側で自動的に連携・実行します。

1. **`inspect_html.py`（事前検査スクリプト）**
   - 修正作業に入る前に、対象のHTMLファイルを読み込んでコードの現状（構造や既存の記述）を自動チェックします。
2. **`update-workflow.md`（修正の規約・ルール）**
   - 「コードを書き換える際は、この手順とルールを守りなさい」という開発規約が書かれたMarkdownファイルです。AIはこの規約を遵守してコードを編集します。
3. **`check_update.py`（事後検証スクリプト）**
   -  AIがコードを書き換えた直後に自動で実行されます。変更内容が正しく適用されているか、コードに構文エラー（Syntax Error）が発生していないかを検証します。
4. **`make_report.py`（報告書作成スクリプト）**
   -  すべての工程が完了した後に実行されます。「どのような検査・テストを行い、どこをどう修正したか」のログをまとめ、Markdown形式の完了レポートファイルを自動生成します。

## ③ 初めて使う方のための実行手順（使い方）

プログラミングの知識がない方でも、パソコンに **Python** と **Claude Code（CLI環境）** が入っていれば、以下の3ステップでこの自動化を体験できます。

### 1. 黒い画面（ターミナル）を開く
特典フォルダをパソコンにダウンロードして解凍したら、ターミナル（Mac）やコマンドプロンプト（Windows）を開き、このフォルダの場所に移動します。

### 2. Claude を起動する
画面に以下のコマンドを打ち込み、Enterキーを押してClaudeを立ち上げます。

```bash
claude
```

*※コードは注意してご使用ください。*

### ④ AIにスキルの名前を指定して指示を出す
チャット画面が表示されたら、以下のようにスキルの名前（`html-tool-update`）をメッセージに含めて指示を出します。

* **指示の出し方の例:**
  > html-tool-update の手順に従って、01_tool/mail-generator-base.html に「入力内容をクリアするボタン」を安全に追加してください。

あとはAIが自動的に「事前検査 ➡ ルール遵守での修正 ➡ 修正後のテスト ➡ レポート作成」までをノンストップで実行するのを待つだけです。完了すると、フォルダ内に新しく報告書（レポートファイル）が作成されます。

以上です。
